# Deuteron wave functions

The S and D waves u(r), w(r) of every model, normalised to ∫(u² + w²) dr = 1, on 0 < r ≤ 20 fm. They are the input of everything in this repository. For the published models the numbers come from the authors' tables or parametrisations; please cite the original papers. For My_Model_first_principle they are the S and D waves of the full light-front solution (which has, in addition, a 1.6% spin-singlet relativistic component). Model-20, the six-quark holographic model, has no nucleon–nucleon wave function.
